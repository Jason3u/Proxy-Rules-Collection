# Quantumult-X-Rules

Quantumult X 自建分流规则，供个人 QX 配置的 `[filter_remote]` 引用。

## 规则列表

| 文件 | 说明 | 策略组 |
|---|---|---|
| `X.list` | X(Twitter) 分流，基于 blackmatrix7 的 Twitter.list 移除 grok.com | X平台 |
| `Bybit.list` | Bybit 交易所分流（bm7 无此规则） | 交易所选择 |
| `Bitget.list` | Bitget 交易所分流（bm7 无此规则） | 交易所选择 |
| `Gate.list` | Gate 交易所分流（bm7 无此规则） | 交易所选择 |
